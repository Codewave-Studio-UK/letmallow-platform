# LetMallow

Codewave Studio’s residential rental platform, currently in alpha, for England and Wales, including their islands.

Canonical repository: [Codewave-Studio-UK/letmallow-platform](https://github.com/Codewave-Studio-UK/letmallow-platform).

LetMallow is the selected project name. Commercial trade mark clearance remains outstanding. The full alpha implementation is hosted separately and still needs to be synchronised into this repository.

Development flows through feature branches into `dev`. A stable release to `main` requires a separate release decision.
